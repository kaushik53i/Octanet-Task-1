# 🍽️ Kaushik_Bite - Restaurant Landing Page

A visually appealing, responsive landing page for a restaurant, built using **HTML** and **CSS**. This project is designed to showcase food items with images, descriptions, and prices in a clean and modern layout.

## 🚀 Features

- ✅ Responsive hero banner with background image
- ✅ About, Menu, and Contact sections
- ✅ Interactive menu items with hover effects
- ✅ Navigation bar with smooth hover and zoom animation
- ✅ Simple and clean design with readable layout

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox & Grid)
